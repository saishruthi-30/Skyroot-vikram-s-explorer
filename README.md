# 🚀 Skyroot Vikram-S Explorer

An interactive **2D and 3D model** of **Vikram-S**, the rocket built by Skyroot Aerospace and launched from Sriharikota in November 2022. It was India's first privately developed rocket to reach space.

🔗 **Live demo:** https://saishruthi-30.github.io/Skyroot-vikram-s-explorer/

## ✨ Features

- **3D model:** drag to rotate, scroll or pinch to zoom, and use auto-rotate.
- **2D model:** a blueprint-style side view with the same parts and labels.
- **Hover labels:** hover or tap any part to see a short description and its material.
- **Exploded view:** pull the rocket apart to see every section.
- **Launch simulation:** a lift-off animation with an engine flame, in both 2D and 3D.
- **Info panel:** an overview of the mission, a parts guide, and the materials used.

## 🧩 Parts covered

Nose cone and fairing, payload bay, avionics bay, spin-stabilisation thrusters, solid rocket motor, fins and nozzle.

## 🛠️ Built with

- HTML, CSS and JavaScript
- [Three.js](https://threejs.org/) (r128) for the 3D model
- SVG for the 2D model

## ▶️ How to run

1. Download or clone this repository.
2. Open `index.html` in any modern browser.

No installation is needed. An internet connection is required to load Three.js from the CDN.

```bash
git clone https://github.com/YOUR-USERNAME/Skyroot-vikram-s-explorer.git
```
